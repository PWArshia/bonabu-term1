# Programming Exercises — Python & Java

A collection of **300+ programming exercises** solved in both **Python** and **Java**.

The exercises are based on the *Computer Programming Exercise Collection — Version 1.4*, prepared for the Computer Engineering Department of **Bonab University**.

The goal of this repository is to improve programming fundamentals, problem-solving skills, algorithmic thinking, and familiarity with implementing the same solution in different programming languages.

---

## 📘 Exercise Book

An English version of the original exercise collection is included in this repository:

**View Programming Exercises PDF**

The original collection contains exercises ranging from very basic programming problems to more advanced topics such as numerical methods, large-number arithmetic, matrices, expression evaluation, and final programming projects.

---

## 💻 Languages

Every exercise is intended to be implemented in:

* 🐍 **Python**
* ☕ **Java**

This makes it possible to compare different approaches, syntax, and language features while solving the same problem.

## 🚀 Running Solutions

### Python

Make sure Python is installed:

```bash
python --version
```

Run a solution:

```bash
python solution.py
```

or:

```bash
python3 solution.py
```

### Java

Make sure the JDK is installed:

```bash
java --version
javac --version
```

Compile the program:

```bash
javac Solution.java
```

Run it:

```bash
java Solution
```
